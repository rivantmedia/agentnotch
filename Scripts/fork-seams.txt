# Agent Notch's edits to upstream Codenotch files (design §3).
#
# Scripts/check-seams.sh reads this file. After a merge from upstream, any
# SEAM line it reports missing has to be re-applied by hand, in the same
# place (the design names the anchor for each), with its `// Fork:` tag.
#
# Format, tab-separated:
#   SEAM   <id>   <file>   <text that must appear in the file, verbatim>   [<n>]
#                          with <n>: on at least n lines (one per call path)
#   FORBID <id>   <file>   <text that must not appear on a line of the file
#                          that isn't a comment (#, //, @# after indentation)>
#   ALLOW  <path or glob>          a path under Sources/ or Tests/ that may
#                                  differ from upstream (everything else may not)
#
# Globs: a trailing /** matches everything below a folder.
